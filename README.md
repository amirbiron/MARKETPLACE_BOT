## 🆕 מה חדש בגרסה 1.2

### 🛡️ Anti-Fraud אוטומטי

מערכת זיהוי ומניעת הונאות אוטומטית:

| תכונה | תיאור |
|--------|--------|
| 🔍 **זיהוי קופונים כפולים** | זיהוי אותו קוד דיגיטלי במספר קופונים |
| 📊 **זיהוי מוכר עם מחלוקות גבוהות** | התראה מעל 20% מחלוקות |
| 📈 **זיהוי דפוס החזרים חריג** | קונים עם יותר מ-30% החזרים |
| 💰 **זיהוי מחירים חשודים** | הנחה מעל 90% או מחיר נמוך מ-5₪ |
| ⚡ **זיהוי פעילות מהירה מדי** | הרבה עסקאות בזמן קצר |
| 🚫 **חסימה אוטומטית** | חסימה זמנית למשתמשים חשודים |
| 🔔 **התראות לאדמינים** | התראה בזמן אמת על פעילות חשודה |
| ✅ **אימות עסקאות גדולות** | דרישת אימות לעסקאות מעל 500₪ |
| 📉 **הגבלת מוכרים חדשים** | 5 קופונים ביום ב-30 הימים הראשונים |

#### 🏆 ניקוד אמינות (Trust Score)

ניקוד 0-100 לכל מוכר על בסיס:
- גיל חשבון
- מספר עסקאות מוצלחות
- אחוז מחלוקות
- סטטוס אימות (מאומת/לא מאומת)
- דירוג ממוצע

**יתרונות לניקוד גבוה:**
| ניקוד | יתרון |
|--------|--------|
| 80+ | הנחה 50% בעמלות |
| 60-79 | הנחה 30% בעמלות |
| 40-59 | הנחה 10% בעמלות |
| מתחת ל-20 | הגבלות ובדיקות נוספות |

### 💰 Escrow אמיתי

מערכת Escrow מלאה עם הפרדת כספים:

```
קונה משלם → Escrow → [24 שעות המתנה] → מוכר
                ↓ [אם מחלוקת]
           החזר לקונה
```

| תכונה | תיאור |
|--------|--------|
| 🔒 **חשבון נפרד** | כספים מוחזקים בנפרד מיתרות משתמשים |
| ⏰ **שחרור אוטומטי** | שחרור למוכר אחרי 24 שעות ללא דיווח |
| ↩️ **החזר מיידי** | החזר מלא במקרה של מחלוקת |
| 📋 **לוג מפורט** | תיעוד כל תנועת כספים |
| 📊 **דוחות התאמה** | דוח התאמה יומי אוטומטי |
| 👨‍💼 **ממשק אדמין** | צפייה, שחרור ידני, דוחות |

## 🚀 התקנה והרצה

### דרישות מערכת
- Python 3.9+
- MongoDB 5.0+
- Telegram Bot Token (מ-@BotFather)

### התקנה מקומית

```bash
# 1. שכפול הפרויקט
git clone https://github.com/amirbiron/MARKETPLACE_BOT.git
cd MARKETPLACE_BOT

# 2. יצירת סביבה וירטואלית
python -m venv venv
source venv/bin/activate  # Linux/Mac
# או: venv\Scripts\activate  # Windows

# 3. התקנת תלויות
pip install -r requirements.txt

# 4. הגדרות סביבה
cp .env.example .env
# ערוך את .env עם הפרטים שלך

# 5. הרצת הבוט
python main.py
```

### Deploy ל-Render

הפרויקט מוכן ל-deploy ב-Render:
1. צור חשבון ב-[render.com](https://render.com)
2. חבר את ה-GitHub repo
3. הגדר את משתני הסביבה
4. Deploy!

## ⚙️ הגדרות

### משתני סביבה (.env)

```bash
# Telegram Bot Token
BOT_TOKEN=your_bot_token_here

# MongoDB
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/
MONGODB_DB_NAME=marketplace_bot

# Admin User IDs (comma-separated)
ADMIN_IDS=123456789,987654321

# Environment
ENVIRONMENT=production  # או development

# Payment Details (אופציונלי)
BIT_PHONE=050-1234567
PAYBOX_LINK=https://paybox.co.il/...
BANK_NAME=לאומי
BANK_BRANCH=123
BANK_ACCOUNT=1234567
BANK_OWNER=שם בעל החשבון
MIN_DEPOSIT_AMOUNT=50

# 🆕 Payment Gateway (v1.2)
PAYMENT_GATEWAY_ENABLED=false  # true להפעלת סליקה
PAYMENT_GATEWAY=tranzila  # tranzila/cardcom/payplus/meshulam

# Tranzila
TRANZILA_TERMINAL=your_terminal
TRANZILA_PASSWORD=your_password

# CardCom
CARDCOM_TERMINAL=your_terminal
CARDCOM_USERNAME=your_username
CARDCOM_API_KEY=your_key

# PayPlus
PAYPLUS_API_KEY=your_key
PAYPLUS_SECRET_KEY=your_secret
PAYPLUS_TERMINAL_UID=your_uid

# Meshulam
MESHULAM_PAGE_CODE=your_code
MESHULAM_USER_ID=your_id
MESHULAM_API_KEY=your_key

# Webhook
WEBHOOK_BASE_URL=https://your-domain.com
WEBHOOK_SECRET=your_secret

# 🆕 Auto Payout (v1.2)
AUTO_PAYOUT_ENABLED=false
PAYPAL_CLIENT_ID=your_id
PAYPAL_CLIENT_SECRET=your_secret
PAYONEER_PROGRAM_ID=your_id
PAYONEER_API_KEY=your_key
```
